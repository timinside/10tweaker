## ✨ About

This folder contains the open source code of **10tweaker** (formerly XTweaker), a tool for improving and customizing your Windows experience. You are welcome to read it, learn from it, build it yourself, and help make it better.

## 📥 Getting the code

Clone the repository and open this folder:

```bash
git clone -b sources --single-branch https://github.com/timinside/10tweaker.git
cd 10tweaker
```

Prefer no Git? Use **Code → Download ZIP** on the repository page.

## 🤝 Contributing

1. Fork the repository.
2. Create a branch for your change.
3. Make and test your changes (use a restore point or a virtual machine).
4. Open a pull request describing what you changed and why.

For bigger changes, please open an issue first so we can discuss the idea.

## 🐛 Bugs and ideas

Found a bug or have an idea? [Open an issue](https://github.com/timinside/10tweaker/issues/new/choose). The templates will guide you.
