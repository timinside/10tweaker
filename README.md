## ✨ What is 10tweaker?

10tweaker lets you adjust a wide range of Windows settings and optimize your workflow, all from one place. Whether you like to dig into every option yourself or just want things to work better without the hassle, it keeps the path short.

## 🚀 Features

| | |
|---|---|
| 🎛️ **Flexible customization** | Adjust Windows settings to fit the way you work. |
| ⚡ **Workflow optimization** | Streamline your system and make your daily routine smoother. |
| 🧹 **System cleanup** | Clear out clutter and free up space. |
| 🔒 **Privacy controls** | Manage telemetry and data-sharing options. |
| 🎨 **Appearance tweaks** | Customize the look and feel of Windows. |
| 🧰 **Built-in tools** | A set of handy utilities, such as WinPEToRE and XClean. |

## 🧰 Tools

Besides tweaks, 10tweaker comes with a set of handy tools.

| Tool | What it does |
|---|---|
| **WinPEToRE** | Installs WinPE as the system Recovery environment. |

## 🔄 How it works

**🛟 Back up** ➜ **🎛️ Pick tweaks** ➜ **✅ Apply** ➜ **🎉 Enjoy**

1. **Back up** your system by creating a restore point.
2. **Pick** the tweaks you want.
3. **Apply** the changes.
4. **Enjoy** a Windows that works the way you like.

## 🛟 Before you start

Tweaks change system settings, so always create a restore point first. It takes a minute:

1. Press **Start**, type **Create a restore point**, and open it.
2. On the **System Protection** tab, select your system drive. If protection is off, click **Configure** and turn it on.
3. Click **Create**, give the point a name, and confirm.

If something does not feel right later, you can roll back with **System Restore**.
