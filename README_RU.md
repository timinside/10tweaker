> [!WARNING]
> 10tweaker меняет системные настройки Windows. Перед тестированием собственных сборок создайте точку восстановления или используйте виртуальную машину.

## ✨ О папке

В этой папке лежит открытый исходный код **10tweaker** (ранее XTweaker), инструмента для улучшения и настройки вашей работы с Windows. Вы можете читать его, учиться на нём, собирать самостоятельно и помогать делать проект лучше.

## 📥 Как получить код

Склонируйте репозиторий и откройте эту папку:

```bash
git clone https://github.com/timinside/10tweaker.git
cd 10tweaker/sources
```

Не хотите использовать Git? Нажмите **Code → Download ZIP** на странице репозитория.

## 🤝 Как помочь проекту

1. Сделайте форк репозитория.
2. Создайте ветку для своих изменений.
3. Внесите изменения и протестируйте их (используйте точку восстановления или виртуальную машину).
4. Откройте pull request с описанием того, что и зачем вы изменили.

Для крупных изменений сначала создайте issue, чтобы мы обсудили идею.

## 🐛 Баги и идеи

Нашли баг или есть идея? [Создайте issue](https://github.com/timinside/10tweaker/issues/new/choose). Шаблоны подскажут, что нужно указать.
