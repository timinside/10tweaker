## ✨ Что такое 10tweaker?

10tweaker позволяет настраивать множество параметров Windows и оптимизировать рабочий процесс в одном месте. Любите разбираться в каждой опции сами или просто хотите, чтобы всё работало лучше без лишних хлопот, путь к результату здесь короткий.

## 🚀 Возможности

| | |
|---|---|
| 🎛️ **Гибкая настройка** | Настраивайте параметры Windows так, как удобно вам. |
| ⚡ **Оптимизация рабочего процесса** | Упростите систему и сделайте повседневную работу плавнее. |
| 🧹 **Очистка системы** | Избавляйтесь от лишнего и освобождайте место. |
| 🔒 **Приватность** | Управляйте телеметрией и параметрами передачи данных. |
| 🎨 **Внешний вид** | Настраивайте оформление Windows. |
| 🧰 **Встроенные инструменты** | Набор полезных утилит, например WinPEToRE и XClean. |

## 🧰 Инструменты

Помимо твиков, в 10tweaker есть набор полезных инструментов.

| Инструмент | Что делает |
|---|---|
| **WinPEToRE** | Устанавливает WinPE как системную среду восстановления (Recovery). |
| **XClean** | Быстрые действия прямо из системного трея, по аналогии с [LunaClean](https://github.com/timinside/LunaClean). |

## 🔄 Как это работает

**🛟 Резервная копия** ➜ **🎛️ Выбрать твики** ➜ **✅ Применить** ➜ **🎉 Пользоваться**

1. **Подстрахуйтесь**: создайте точку восстановления.
2. **Выберите** нужные твики.
3. **Примените** изменения.
4. **Наслаждайтесь** Windows, который работает так, как нравится вам.

## 🛟 Перед началом

Твики меняют системные настройки, поэтому всегда сначала создавайте точку восстановления. Это занимает минуту:

1. Нажмите **Пуск**, введите **Создание точки восстановления** и откройте её.
2. На вкладке **Защита системы** выберите системный диск. Если защита отключена, нажмите **Настроить** и включите её.
3. Нажмите **Создать**, задайте имя точки и подтвердите.

Если позже что-то пойдёт не так, можно откатиться через **Восстановление системы**.

### Установка за 3 шага

1. Скачайте офлайн-установщик `10tweakerSetup.exe` по кнопке выше.
2. Запустите установщик.
3. Следуйте инструкциям на экране и запустите 10tweaker.

## ❓ Частые вопросы

<details>
<summary><b>Точка восстановления действительно нужна?</b></summary>

Да, это настоятельно рекомендуется. Твики меняют системные настройки, а точка восстановления позволяет откатиться, если что-то пойдёт не так.
</details>

<details>
<summary><b>Куда делся XTweakerBETA?</b></summary>

Репозиторий XTweakerBETA более не активен. Бета-версии теперь публикуются в этом репозитории, который стал основным и единственным.
</details>

<details>
<summary><b>Этот репозиторий всё ещё в архиве?</b></summary>

Нет. Проект более не архивирован. Репозиторий только что обновлён: новый README и кнопка доната.
</details>

<details>
<summary><b>Я нашёл баг. Куда о нём сообщить?</b></summary>

</details>
